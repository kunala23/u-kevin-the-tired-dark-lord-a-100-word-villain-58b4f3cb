A ~100-word monologue for a fantasy villain who is secretly just very tired. The tiredness lives in the voice, the rhythm and the small deflections — never in a plain statement of weariness — while the speaker stays a villain with a scheme and a history: thirty years keeping the Ashen Spire standing, the eclipse tithe, the mirror-spies, the treaty in crow's blood. The program writes the monologue to `/output/entry.txt` (588 characters, 106 words, inside the 1–600 character gate).

## Run it

```sh
node main.ts
```
